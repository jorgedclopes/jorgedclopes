  - Contributed to enterprise-grade pipelines for automated customer identification, processing hundreds of thousands of records daily.

  - Technical Team Lead for a team of 7, onboarding 3 cross-functional teams onto a distributed nano-service platform.
  - Developed several features in a nano-service project.
